## Fixture policy (postmortem rule)

Test fixtures must be built from real system dumps, never invented. Fixture builder: extract a small real slice of a run dir's loop-checkpoints.sqlite (a few threads) plus real audit rows; sanitize absolute paths (/Users/luke/... -> a tmp workspace prefix) so no machine-specific paths are committed; keep structure, channels, and verdict sequences byte-true. Only edge cases (corrupt blob, missing table) use hand-built synthetic rows, and they are labeled synthetic.
