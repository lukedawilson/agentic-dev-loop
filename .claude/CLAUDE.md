# yosk-sitebuilder - Claude Code project instructions

See also `AGENTS.md` for language-agent-global rules (OpenCode and Claude share that file).

## Frontend development

**Always** apply [frontend development rules](.opencode/skills/frontend-development/SKILL.md) to **any** frontend changes.

## Shared design workflow

This repo supports a two-way Figma bridge. See `DESIGN.md` for full details. The Figma MCP server is configured in `opencode.jsonc`. In Claude Code, enable the Figma MCP server manually or use `tools/import-opencode-tools.sh` to copy commands into your local Claude setup.

## Commands and skills

Project commands (`.claude/commands/`) and skills (`.claude/skills/`) are generated by `tools/import-opencode-tools.sh`, which syncs `.opencode/commands/` and `.opencode/skills/` into this directory. Run that script after any change to the OpenCode source of truth.
